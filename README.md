# Shadow Garage

A premium automotive detailing landing page built with React and Vite.

Shadow Garage is a fictional luxury car detailing brand designed to showcase a modern automotive web experience with cinematic visuals, premium UI design, smooth animations, and vehicle-specific pricing.

## Overview

Shadow Garage is inspired by high-end detailing studios and luxury automotive brands. The project focuses on delivering a visually engaging experience while maintaining responsive design and performance.

The landing page includes:

* Cinematic hero section
* Premium automotive branding
* Vehicle-specific pricing system
* Interactive package selection
* Smooth animations
* Glassmorphism UI elements
* Mobile-first responsive design
* Luxury dark theme aesthetic

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/shadow-garage.git
```

Navigate to the project directory:

```bash
cd shadow-garage
```

Install dependencies:

```bash
npm install
```

## Running Locally

Start the development server:

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

## Production Build

Generate a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## GitHub Pages Deployment

Build and deploy:

```bash
npm run deploy
```

Make sure the following are configured:

### package.json

```json
"homepage": "https://your-username.github.io/shadow-garage"
```

### vite.config.js

```javascript
base: "/shadow-garage/"
```
